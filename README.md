# PostgreSQL Learning

A hands-on repository documenting my practice and exploration of **PostgreSQL and SQL**, covering database fundamentals, CRUD operations, constraints, relationships, joins, aggregate functions, subqueries, indexing, and transactions.

The repository contains SQL scripts, practical examples, and exercises organized by topic.

## Topics Covered

### 1. Database Fundamentals
- Database Creation
- Schema Creation
- Table Creation
- SQL Data Types
- NULL, Empty String, and Zero Values

### 2. Constraints and Keys
- SQL Constraints
- Primary Keys
- Data Integrity

### 3. CRUD Operations
- INSERT
- SELECT
- UPDATE
- DELETE
- RETURNING Clause

### 4. Filtering and Sorting
- WHERE Clause
- AND, OR, NOT
- LIKE Pattern Matching
- IN and NOT IN
- BETWEEN
- IS NULL and IS NOT NULL
- ORDER BY
- LIMIT and OFFSET
- Pagination

### 5. Relationships
- Foreign Keys
- One-to-Many Relationships
- Many-to-Many Relationships
- Database Seeding

### 6. SQL Joins
- INNER JOIN
- LEFT JOIN
- Table Aliases

### 7. Aggregate Functions
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- GROUP BY
- HAVING
- COUNT DISTINCT

### 8. Advanced SQL Concepts
- Subqueries
- Indexes
- Database Transactions
